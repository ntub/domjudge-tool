# CLI Reference

Complete flag-by-flag reference for `domjudge-tool`. For a quick-start
overview and architecture notes see [`README.md`](../README.md).

For Traditional Chinese, see [`CLI.zh-TW.md`](CLI.zh-TW.md).

## Supported DOMjudge Versions

| Version | Transport |
| ------- | --------- |
| 7.3.x   | REST API v4 (create / set-password) + HTML scraper fallback |
| 8.3.1   | HTML scraper (write operations) + REST API v4 (read operations) |

Set the `version` field in `domserver.json` (or `--version` in
`gen-config`) to select the correct web gateway.

## Global Flags

These flags are available on every command.

| Flag | Short | Default | Description |
| ---- | ----- | ------- | ----------- |
| `--config` | `-c` | `domserver.json` | Path to the config file |
| `--verbose` | `-v` | — | Log verbosity; `-v` = info, `-vv` = debug |
| `--disable-ssl` | — | `false` | Skip TLS certificate verification (overrides config) |
| `--no-progress` | — | `false` | Disable the per-row progress bar; auto-disabled when stderr is not a TTY, `NO_COLOR` is set, or `TERM=dumb` |

## Configuration: `domserver.json`

Generated by `gen-config`. All fields use snake_case JSON keys.

| Field | Type | Default | Description |
| ----- | ---- | ------- | ----------- |
| `host` | string | — | DOMjudge server URL (required) |
| `username` | string | — | Admin or API user (required) |
| `password` | string | — | User password (required) |
| `disable_ssl` | bool | `false` | Skip TLS verification |
| `version` | string | `"7.3.2"` | DOMjudge version; controls web gateway selection |
| `api_version` | string | `"v4"` | REST API version |
| `timeout` | float \| null | null | HTTP timeout in seconds (null = no timeout) |
| `max_connections` | int \| null | null | Maximum concurrent HTTP connections |
| `max_keepalive_connections` | int \| null | null | Maximum keepalive connections |
| `category_id` | int \| null | null | Default team category id |
| `affiliation_id` | int \| null | null | Fallback affiliation id when CSV column is empty |
| `affiliation_country` | string \| null | `"TWN"` | Country code for new affiliations |
| `user_roles` | int[] | `[]` | Default user role ids |
| `contest_id` | string \| null | null | Pin to a specific contest (numeric id or shortname); null auto-detects the single active contest |
| `prefer_scraper` | bool \| null | null | Force all hybrid commands onto the HTML scraper path |

## Commands

### General

#### `gen-config`

Write a `domserver.json` from flags. Does not contact the server.

```bash
domjudge-tool gen-config --host https://judge.example.org \
    --username admin --password secret
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--host` | — | DOMjudge host URL (required) |
| `--username` | — | Admin username (required) |
| `--password` | — | User password (required) |
| `-o, --output` | `domserver.json` | Output path for the config file |
| `--version` | `7.3.2` | DOMjudge version |
| `--api-version` | `v4` | DOMjudge API version |
| `--disable-ssl` | `false` | Skip TLS verification |
| `--timeout` | — | HTTP timeout in seconds |
| `--max-connections` | — | HTTP max connections |
| `--max-keepalive-connections` | — | HTTP max keepalive connections |
| `--category-id` | `0` | Default team category id |
| `--affiliation-id` | `0` | Default affiliation id |
| `--affiliation-country` | `TWN` | Default affiliation country |
| `--user-roles` | — | Default user role ids (comma-separated) |
| `--contest-id` | — | Default contest id (numeric or shortname) |

#### `version`

Print the build version and exit.

```bash
domjudge-tool version
```

No command-specific flags.

### User & Team

#### `import-users-teams-example`

Write the canonical CSV template to disk. Fill in the template and
pass it to `import-users-teams`.

```bash
domjudge-tool import-users-teams-example
domjudge-tool import-users-teams-example -o my-contest.csv
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `-o, --output` | `import-users-teams.csv` | Output path for the template |

#### `import-users-teams`

Reconcile a CSV file against the live user list. Creates users and
teams that are missing; optionally updates or deletes existing rows.

```bash
domjudge-tool import-users-teams import-users-teams.csv
domjudge-tool import-users-teams import-users-teams.csv \
    --delete-existing --category-id 3
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--category-id` | `0` | Default team category id |
| `--affiliation-id` | `0` | Fallback affiliation id when CSV column is empty |
| `--affiliation-country` | cfg value | Country for new affiliations |
| `--user-roles` | — | User role ids (comma-separated) |
| `--enabled` | `true` | Leave each created user enabled |
| `--ignore-existing` | `false` | Skip rows whose username already exists |
| `--delete-existing` | `false` | Delete then recreate rows whose username already exists |
| `--password-length` | `0` | Length when generating passwords (0 = library default) |
| `--password-pattern` | — | Charset when generating passwords |
| `--new-password` | `false` | Always regenerate passwords, even when CSV provides one |

#### `export-users`

Export the live user list to CSV or JSON. Alias: `user-list`.

```bash
domjudge-tool export-users
domjudge-tool export-users --format json -o users.json
domjudge-tool export-users --ids 1,2,3
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--format` | `csv` | Output format: `csv` or `json` |
| `-o, --output` | stdout | Output file |
| `--ids` | — | Comma-separated user ids to include |
| `--team-id` | — | Filter by team id |

#### `rm-teams-and-users`

Delete users and their teams. Alias: `rm-teams`.

Protected accounts (`admin`, `judgehost`, and the config `username`)
are always skipped. The `--exclude` / `--include` flags follow an
inverted-filter convention preserved for Python CLI compatibility: do
not change without an ADR.

```bash
domjudge-tool rm-teams-and-users
domjudge-tool rm-teams-and-users --exclude contestant1,contestant2
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--exclude` | — | Usernames to keep (in addition to protected accounts) |
| `--include` | — | Usernames to delete (default: all non-protected) |

#### `set-password`

Reset a single user's password.

```bash
domjudge-tool set-password alice --password newsecret
domjudge-tool set-password alice --password-length 16
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--password` | — | New password (generated when omitted) |
| `--password-length` | `0` | Length when generating (0 = library default) |
| `--password-pattern` | — | Charset when generating |
| `--user-roles` | — | User role ids (comma-separated) |
| `--enabled` | `true` | Keep the user enabled after the update |

### Email

#### `email-template-example`

Scaffold a template directory containing `subject.txt`, `body.txt`,
and `body.html` with all six supported placeholders.

```bash
domjudge-tool email-template-example
domjudge-tool email-template-example -o ./my-template --force
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `-o, --output` | `./email-template` | Output directory for the template |
| `-f, --force` | `false` | Overwrite existing template files |

#### `email-template-validate`

Verify a template directory loads and references only the six
supported placeholders. Exits non-zero on error.

```bash
domjudge-tool email-template-validate ./my-template
```

No command-specific flags.

#### `render-user-accounts`

Render per-recipient RFC 5322 `.eml` files to disk without touching
SMTP. Useful for review, batch submission, and mailmerge workflows.

```bash
domjudge-tool render-user-accounts users.csv ./my-template
domjudge-tool render-user-accounts users.csv ./my-template \
    -d ./output --from-email contest@example.org --force
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `-d, --output-dir` | `./rendered-emails` | Output directory for `.eml` files |
| `--from-email` | `noreply@localhost` | `From:` header value; also used as recipient-fallback domain |
| `--force` | `false` | Overwrite existing `.eml` files |

#### `send-user-accounts`

Mail templated credential emails directly via SMTP.

SMTP credentials (`--smtp-username` / `--smtp-password`) are separate
from the DOMjudge admin auth in `domserver.json`.

```bash
domjudge-tool send-user-accounts users.csv ./my-template \
    --host smtp.example.org --port 587 \
    --smtp-username mailer --smtp-password secret \
    --from-email contest@example.org
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--host` | `localhost` | SMTP server host |
| `--port` | `25` | SMTP server port |
| `--from-email` | `noreply@localhost` | `From:` header value |
| `--use-ssl` | `false` | TLS-on-connect (not STARTTLS) |
| `--smtp-username` | — | SMTP AUTH username (empty skips AUTH) |
| `--smtp-password` | — | SMTP AUTH password (empty skips AUTH) |
| `--timeout` | `0` | SMTP dial timeout (`0` = no timeout) |

### Problems

#### `download-problems`

Log in via the configured jury credentials, list the contest's
problems, and write each problem's export ZIP to disk.

```bash
domjudge-tool download-problems
domjudge-tool download-problems --folder ./zips --only A,B,C
domjudge-tool download-problems --exclude D,E
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--folder` | `export_problems` | Output folder |
| `--exclude` | — | Comma-separated problem ids to exclude |
| `--only` | — | Comma-separated problem ids to keep (excludes all others) |

### Scoreboard

#### `download-scoreboard`

Export the public scoreboard as CSV. Alias: `scoreboard-export`.

Output columns: `Rank, TeamAffiliation, TeamName, SolvedCount, Score,
Category, <problem labels…>`. Since v1.4.0 the output spans every
team category (one ranked section per `sortorder`; `Rank` restarts at 1
per section).

```bash
domjudge-tool download-scoreboard --cid 1
domjudge-tool download-scoreboard --cid 1 \
    --filename results --path ./output --exclude-hidden
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--cid` | — | DOMjudge contest id (required) |
| `--filename` | `export` | Output filename without extension (`.csv` appended) |
| `--path` | cwd | Directory to write the CSV |
| `--exclude-hidden` | `false` | Exclude hidden team categories (e.g. System) |
| `--url` | cfg `host` | Override the scoreboard host |

### Submissions

#### `download-submissions`

Download every submission's source archive for a contest.
Alias: `contest-files`.

```bash
domjudge-tool download-submissions 1
domjudge-tool download-submissions 1 --mode 1 --path ./dl --no-extract
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--mode` | `2` | Folder layout: `1`=team-first, `2`=problem-first, other=`contest_<cid>` |
| `--path` | — | Output path prefix |
| `--extract` | `true` | Unzip each downloaded archive in place |
| `--strict` | `false` | Forwarded to the API v4 submissions list query (Python parity) |

## CSV Format

`import-users-teams`, `render-user-accounts`, and `send-user-accounts`
all consume the same CSV format. The file is BOM-tolerant (UTF-8 BOM
is stripped automatically).

| Column | Required | Description |
| ------ | -------- | ----------- |
| `username` | Yes | Unique login name |
| `name` | Yes | Display name |
| `email` | No | Email address (empty = no email set on the account) |
| `affiliation` | Yes | Organisation / affiliation name |
| `password` | No | Plain-text password; generated when empty |

Column order is fixed. Do not add or remove columns.

Generate a starter template with:

```bash
domjudge-tool import-users-teams-example
```

## Email Template Placeholders

`render-user-accounts` and `send-user-accounts` support exactly these
six placeholders in `subject.txt`, `body.txt`, and `body.html`:

| Placeholder | Source |
| ----------- | ------ |
| `$username` | CSV `username` column |
| `$name` | CSV `name` column |
| `$email` | CSV `email` column |
| `$affiliation` | CSV `affiliation` column |
| `$password` | CSV `password` column (or generated value) |
| `$server_host` | `domserver.json` `host` field |

Validate a template directory with:

```bash
domjudge-tool email-template-validate ./my-template
```
