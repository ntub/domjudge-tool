# CLI Reference

Complete flag-by-flag reference for `domjudge-tool`. For a quick-start
overview and architecture notes see [`README.md`](../README.md).

For Traditional Chinese, see [`CLI.zh-TW.md`](CLI.zh-TW.md).

## Supported DOMjudge Versions

| Version | Transport |
| ------- | --------- |
| 7.3.x   | REST API v4 (create / set-password) + HTML scraper fallback |
| 8.3.1   | HTML scraper (write operations) + REST API v4 (read operations) |

Set the `version` field in `domserver.json` (or `--version` in
`gen-config`) to select the correct web gateway.

## Global Flags

These flags are available on every command.

| Flag | Short | Default | Description |
| ---- | ----- | ------- | ----------- |
| `--config` | `-c` | `domserver.json` | Path to the config file |
| `--verbose` | `-v` | — | Log verbosity; `-v` = info, `-vv` = debug |
| `--disable-ssl` | — | `false` | Skip TLS certificate verification (overrides config) |
| `--no-progress` | — | `false` | Disable the per-row progress bar; auto-disabled when stderr is not a TTY, `NO_COLOR` is set, or `TERM=dumb` |

## Configuration: `domserver.json`

Generated by `gen-config`. All fields use snake_case JSON keys.

| Field | Type | Default | Description |
| ----- | ---- | ------- | ----------- |
| `host` | string | — | DOMjudge server URL (required) |
| `username` | string | — | Admin or API user (required) |
| `password` | string | — | User password (required) |
| `disable_ssl` | bool | `false` | Skip TLS verification |
| `version` | string | `"7.3.2"` | DOMjudge version; controls web gateway selection |
| `api_version` | string | `"v4"` | REST API version |
| `timeout` | float \| null | null | HTTP timeout in seconds (null = no timeout) |
| `max_connections` | int \| null | null | Maximum concurrent HTTP connections |
| `max_keepalive_connections` | int \| null | null | Maximum keepalive connections |
| `category_id` | int \| null | null | Default team category id |
| `affiliation_id` | int \| null | null | Fallback affiliation id when CSV column is empty |
| `affiliation_country` | string \| null | `"TWN"` | Country code for new affiliations |
| `user_roles` | int[] | `[]` | Default user role ids |
| `contest_id` | string \| null | null | Pin to a specific contest (numeric id or shortname); null auto-detects the single active contest |
| `prefer_scraper` | bool \| null | null | Force all hybrid commands onto the HTML scraper path |

### Configuration Field Semantics

- `host`, `username`, and `password` are used by both REST API clients
  and scraper sessions. API calls use Basic Auth; scraper calls log in
  through the DOMjudge jury UI.
- `disable_ssl` can also be forced by the global `--disable-ssl` flag.
  Use it only for trusted test stations with self-signed certificates.
- `version` selects the scraper implementation. Values in the `7.3.x`
  family use the v7 gateway; values in the `8.3.x` family use the v8
  gateway. Unsupported families fail before any mutation.
- `api_version` is currently `v4`. The API client paths are rooted at
  `/api/v4`.
- `timeout` applies to HTTP clients. `null` means no explicit timeout.
  `max_connections` and `max_keepalive_connections` are retained for
  config compatibility; current HTTP clients do not expose user-visible
  concurrency tuning.
- `category_id` is the default DOMjudge team category/group id used by
  `import-users-teams` and `set-password` API imports. A CSV
  `category_id` cell overrides it for that row.
- `affiliation_id` is the fallback affiliation id when a CSV row leaves
  `affiliation` empty. When `affiliation` is present, the importer
  resolves or creates that affiliation instead.
- `affiliation_country` is used when the importer creates a missing
  affiliation/organization.
- `user_roles` is the default role id list for scraper password writes.
  Passing explicit roles routes password updates through the scraper
  because `accounts.tsv` has no role column.
- `contest_id` scopes contest-aware API reads and imports. If omitted,
  commands that need a contest auto-select only when exactly one active
  contest exists; otherwise they return an error asking you to set it.
- `prefer_scraper=true` forces hybrid operations onto the scraper path
  when a scraper implementation exists. API-only reads remain on the
  API path.

## Commands

### General

#### `gen-config`

Write a `domserver.json` from flags. Does not contact the server.

```bash
domjudge-tool gen-config --host https://judge.example.org \
    --username admin --password secret
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--host` | — | DOMjudge host URL (required) |
| `--username` | — | Admin username (required) |
| `--password` | — | User password (required) |
| `-o, --output` | `domserver.json` | Output path for the config file |
| `--version` | `7.3.2` | DOMjudge version |
| `--api-version` | `v4` | DOMjudge API version |
| `--disable-ssl` | `false` | Skip TLS verification |
| `--timeout` | — | HTTP timeout in seconds |
| `--max-connections` | — | HTTP max connections |
| `--max-keepalive-connections` | — | HTTP max keepalive connections |
| `--category-id` | `0` | Default team category id |
| `--affiliation-id` | `0` | Default affiliation id |
| `--affiliation-country` | `TWN` | Default affiliation country |
| `--user-roles` | — | Default user role ids (comma-separated) |
| `--contest-id` | — | Default contest id (numeric or shortname) |

#### `version`

Print the build version and exit.

```bash
domjudge-tool version
```

No command-specific flags.

### User & Team

#### `import-users-teams-example`

Write the canonical CSV template to disk. Fill in the template and
pass it to `import-users-teams`. The template includes an optional
`category_id` column; leave it blank to use `--category-id` or the
`domserver.json` default.

```bash
domjudge-tool import-users-teams-example
domjudge-tool import-users-teams-example -o my-contest.csv
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `-o, --output` | `import-users-teams.csv` | Output path for the template |

#### `import-users-teams`

Reconcile a CSV file against the live user list. Creates users and
teams that are missing; optionally updates or deletes existing rows.
The CSV accepts an optional `category_id` column. When a row leaves
`category_id` empty, or when the column is omitted entirely, the row
uses the existing `--category-id` / config fallback.

Detailed workflow:

1. Load `domserver.json`, apply command flags, create the API client,
   and create the version-selected web gateway.
2. Log in through the scraper gateway before making changes. This
   catches invalid jury credentials before mutations start.
3. Fetch the live user list from `/api/v4/users` and parse the CSV.
   Duplicate usernames or malformed rows abort before delete/create
   mutations.
4. If `--delete-existing` is set, delete matching existing users and
   teams through the scraper. DOMjudge 7.3.x and 8.3.1 do not expose
   REST DELETE for these resources.
5. Split rows into create, update, or skip cohorts. `--ignore-existing`
   skips existing usernames; otherwise existing rows update the team,
   password, and email fields through the selected route.
6. Resolve affiliation data. A non-empty `affiliation` cell resolves or
   creates that affiliation/organization; an empty cell uses
   `--affiliation-id` or config fallback.
7. Resolve team category data. A non-empty CSV `category_id` cell wins
   for that row; otherwise the command uses `--category-id` or config.
8. Create/update users, set passwords, and backfill email where needed.
   The command writes `import-users-teams-out.csv` with generated or
   effective passwords.

Output:

- `import-users-teams-out.csv` is written in the working directory.
- The output CSV keeps the credential-delivery shape and does not
  include the optional input-only `category_id` column.
- Successful runs print a short summary and the output filename.

```bash
domjudge-tool import-users-teams import-users-teams.csv
domjudge-tool import-users-teams import-users-teams.csv \
    --delete-existing --category-id 3
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--category-id` | `0` | Default team category id |
| `--affiliation-id` | `0` | Fallback affiliation id when CSV column is empty |
| `--affiliation-country` | cfg value | Country for new affiliations |
| `--user-roles` | — | User role ids (comma-separated) |
| `--enabled` | `true` | Leave each created user enabled |
| `--ignore-existing` | `false` | Skip rows whose username already exists |
| `--delete-existing` | `false` | Delete then recreate rows whose username already exists |
| `--password-length` | `0` | Length when generating passwords (0 = library default) |
| `--password-pattern` | — | Charset when generating passwords |
| `--new-password` | `false` | Always regenerate passwords, even when CSV provides one |

#### `export-users`

Export the live user list to CSV or JSON. Alias: `user-list`.

```bash
domjudge-tool export-users
domjudge-tool export-users --format json -o users.json
domjudge-tool export-users --ids 1,2,3
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--format` | `csv` | Output format: `csv` or `json` |
| `-o, --output` | stdout | Output file |
| `--ids` | — | Comma-separated user ids to include |
| `--team-id` | — | Filter by team id |

Detailed workflow:

1. Load config and create a REST API v4 client from `host`,
   `username`, `password`, `disable_ssl`, and `timeout`.
2. Fetch `/api/v4/users`, passing `--ids` and `--team-id` where the API
   accepts them.
3. Re-apply `--ids` and `--team-id` in memory. This preserves behaviour
   on DOMjudge 7.3.x servers that ignore `?team_id=`.
4. Serialize to CSV or JSON. Without `--output`, bytes go to stdout;
   with `--output`, stdout stays empty and the file receives the data.

CSV output contains live DOMjudge user fields. JSON output preserves the
model field names used by this tool.

#### `rm-teams-and-users`

Delete users and their teams. Alias: `rm-teams`.

Protected accounts (`admin`, `judgehost`, and the config `username`)
are always skipped. The `--exclude` / `--include` flags follow an
inverted-filter convention preserved for Python CLI compatibility: do
not change without an ADR.

```bash
domjudge-tool rm-teams-and-users
domjudge-tool rm-teams-and-users --exclude contestant1,contestant2
domjudge-tool rm-teams-and-users --include-csv import-users-teams.csv
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--exclude` | — | Usernames to keep (in addition to protected accounts) |
| `--include` | — | Usernames to delete (default: all non-protected) |
| `--include-csv` | — | Import-users-teams CSV whose usernames should be deleted |

#### `set-password`

Reset a single user's password.

```bash
domjudge-tool set-password alice --password newsecret
domjudge-tool set-password alice --password-length 16
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--password` | — | New password (generated when omitted) |
| `--password-length` | `0` | Length when generating (0 = library default) |
| `--password-pattern` | — | Charset when generating |
| `--user-roles` | — | User role ids (comma-separated) |
| `--enabled` | `true` | Keep the user enabled after the update |

### Email

#### `email-template-example`

Scaffold a template directory containing `subject.txt`, `body.txt`,
and `body.html` with all six supported placeholders.

```bash
domjudge-tool email-template-example
domjudge-tool email-template-example -o ./my-template --force
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `-o, --output` | `./email-template` | Output directory for the template |
| `-f, --force` | `false` | Overwrite existing template files |

#### `email-template-validate`

Verify a template directory loads and references only the six
supported placeholders. Exits non-zero on error.

```bash
domjudge-tool email-template-validate ./my-template
```

No command-specific flags.

#### `render-user-accounts`

Render per-recipient RFC 5322 `.eml` files to disk without touching
SMTP. Useful for review, batch submission, and mailmerge workflows.

```bash
domjudge-tool render-user-accounts users.csv ./my-template
domjudge-tool render-user-accounts users.csv ./my-template \
    -d ./output --from-email contest@example.org --force
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `-d, --output-dir` | `./rendered-emails` | Output directory for `.eml` files |
| `--from-email` | `noreply@localhost` | `From:` header value; also used as recipient-fallback domain |
| `--force` | `false` | Overwrite existing `.eml` files |

#### `send-user-accounts`

Mail templated credential emails directly via SMTP.

SMTP credentials (`--smtp-username` / `--smtp-password`) are separate
from the DOMjudge admin auth in `domserver.json`.

```bash
domjudge-tool send-user-accounts users.csv ./my-template \
    --host smtp.example.org --port 587 \
    --smtp-username mailer --smtp-password secret \
    --from-email contest@example.org
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--host` | `localhost` | SMTP server host |
| `--port` | `25` | SMTP server port |
| `--from-email` | `noreply@localhost` | `From:` header value |
| `--use-ssl` | `false` | TLS-on-connect (not STARTTLS) |
| `--smtp-username` | — | SMTP AUTH username (empty skips AUTH) |
| `--smtp-password` | — | SMTP AUTH password (empty skips AUTH) |
| `--timeout` | `0` | SMTP dial timeout (`0` = no timeout) |

### Problems

#### `download-problems`

Log in via the configured jury credentials and write each selected
problem's export ZIP to disk. When `domserver.json.contest_id` is set
and `--only` is omitted, the command first reads
`/api/v4/contests/{cid}/problems` and uses those problem ids to scope
the scraper download. This avoids downloading the global jury problem
catalog on DOMjudge 7.x.

```bash
domjudge-tool download-problems
domjudge-tool download-problems --folder ./zips --only A,B,C
domjudge-tool download-problems --exclude D,E
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--folder` | `export_problems` | Output folder |
| `--exclude` | — | Comma-separated problem ids to exclude |
| `--only` | — | Comma-separated problem ids to keep (excludes all others) |

#### `import-problems`

Import problem package ZIPs into the configured contest. The command
uses `domserver.json.contest_id` as the target contest id. New imports
omit the optional `problem` form field so DOMjudge creates the problem
from the package metadata. DOMjudge 7.x uses the legacy multipart file
field `zip[]`; DOMjudge 8.x uses `zip`. Use `--problem-id` only when
importing exactly one ZIP to update an existing problem id.

Use `--upsert` to reconcile ZIPs against the configured contest. The command
first reads `/api/v4/contests/{cid}/problems`, derives an identity for each
ZIP, and updates a matching contest problem with `problem=<existing id>`.
ZIPs that do not match the contest problem list are imported through the
current create path. This is tool-side reconciliation, not a native DOMjudge
bulk upsert. `--upsert` and `--problem-id` are mutually exclusive.

For ZIP identity, DOMjudge 8.x prefers `domjudge-problem.ini` `externalid`
when present and falls back to the sanitized filename stem. DOMjudge 7.x uses
the sanitized filename stem because the supported 7.3 import path does not
reliably honour the ini `externalid`. Filename fallback also tries the prefix
before the first underscore so ZIPs produced by `download-problems`
(`{id}_{name}.zip`) can update the original problem id, and trims leading or
trailing `-` / `_` left after unsupported characters are removed. If the
contest problem list contains an ambiguous identity, `--upsert` fails before
uploading.

On DOMjudge 8.x update imports, the multipart ZIP filename is set to the
matched contest problem's `externalid` (or id when `externalid` is empty).
This keeps DOMjudge from deriving a different external id from an operator's
local filename while still updating the matched problem id.

If DOMjudge reports `problem.externalid: This value is already used`, a
global problem package with the same external id already exists. Do not retry
the create path with `--problem-id` unless you intentionally want to update
that existing server problem. On DOMjudge 8.3.1,
`DELETE /api/v4/contests/{cid}/problems/{id}` unlinks a problem from the
contest only; it does not delete the global problem package. In `--upsert`
mode, the first version fails this case with a clear message when the
duplicate global external id is not linked to the configured contest; it does
not auto-link or delete the global problem.

```bash
domjudge-tool import-problems ./export_problems
domjudge-tool import-problems ./export_problems --upsert
domjudge-tool import-problems ./zips/A_easy.zip --problem-id A
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--problem-id` | — | Existing problem id to update for a single ZIP input |
| `--upsert` | `false` | Create missing contest problems and update matching contest problems |

### Scoreboard

#### `download-scoreboard`

Export the public scoreboard as CSV. Alias: `scoreboard-export`.

Output columns: `Rank, TeamAffiliation, TeamName, SolvedCount, Score,
Category, <problem labels…>`. Since v1.4.0 the output spans every
team category (one ranked section per `sortorder`; `Rank` restarts at 1
per section).

```bash
domjudge-tool download-scoreboard --cid 1
domjudge-tool download-scoreboard --cid 1 \
    --filename results --path ./output --exclude-hidden
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--cid` | — | DOMjudge contest id (required) |
| `--filename` | `export` | Output filename without extension (`.csv` appended) |
| `--path` | cwd | Directory to write the CSV |
| `--exclude-hidden` | `false` | Exclude hidden team categories (e.g. System) |
| `--url` | cfg `host` | Override the scoreboard host |

### Submissions

#### `download-submissions`

Download every submission's source archive for a contest.
Alias: `contest-files`.

```bash
domjudge-tool download-submissions 1
domjudge-tool download-submissions 1 --mode 1 --path ./dl --no-extract
```

| Flag | Default | Description |
| ---- | ------- | ----------- |
| `--mode` | `2` | Folder layout: `1`=team-first, `2`=problem-first, other=`contest_<cid>` |
| `--path` | — | Output path prefix |
| `--extract` | `true` | Unzip each downloaded archive in place |
| `--strict` | `false` | Forwarded to the API v4 submissions list query (Python parity) |

## CSV Format

`import-users-teams`, `render-user-accounts`, and `send-user-accounts`
all consume the same credential CSV core. The file is BOM-tolerant
(UTF-8 BOM is stripped automatically).

| Column | Required | Description |
| ------ | -------- | ----------- |
| `username` | Yes | Unique login name |
| `name` | Yes | Display name |
| `email` | No | Email address (empty = no email set on the account) |
| `affiliation` | Yes | Organisation / affiliation name |
| `password` | No | Plain-text password; generated when empty |
| `category_id` | No | Input-only per-row team category override for `import-users-teams`; ignored by email commands |

The first five columns keep the historical order:
`username,name,email,affiliation,password`. `category_id` may be
appended. Older CSV files without `category_id` remain valid.

`import-users-teams` also accepts two compatibility layouts:

- `username,email,affiliation,name`
- `username,name,email,affiliation,password,is_exist`

`is_exist` is used only when reading previously generated output. Do
not put `category_id` in `import-users-teams-out.csv`; it is input-only.

Generate a starter template with:

```bash
domjudge-tool import-users-teams-example
```

## Operation Routing

`domjudge-tool` uses REST API v4 where the API is sufficient and the
HTML scraper where DOMjudge exposes no safe API path. `--verbose` shows
router decisions as structured log lines.

| Operation | Default Route | Reason |
| --------- | ------------- | ------ |
| `version` | API | Reads `/api/v4/version` |
| `export-users` | API | Reads `/api/v4/users`; filters again in memory |
| `download-submissions` | API | Uses submission list and file/source endpoints |
| `download-scoreboard` | API | Reads scoreboard, teams, organizations, and groups, then rebuilds CSV |
| `download-problems` contest scope | API | Reads `/api/v4/contests/{cid}/problems` when `contest_id` is set and `--only` is omitted |
| `download-problems` list | Scraper | Uses versioned jury UI problem listing after any API contest scoping |
| `download-problems` ZIP | Scraper | REST API has no problem ZIP export endpoint |
| `import-problems` | API | Posts problem package ZIPs to `/api/v4/contests/{cid}/problems` |
| `import-problems --upsert` contest index | API | Reads `/api/v4/contests/{cid}/problems` before choosing create vs update |
| `import-users-teams` create/update/password/email | Scraper on v7 and v8 | v7 `accounts.tsv` user-to-team linkage is unsafe; v8 write APIs are not reliable for these fields |
| `import-users-teams` delete-existing | Scraper | REST API has no user/team DELETE |
| `set-password` without explicit `--user-roles` | API on v7, scraper on v8 | v7 `accounts.tsv` password reset is safe; v8 falls back to scraper |
| `set-password` with `--user-roles` | Scraper | `accounts.tsv` has no role column |
| `rm-teams-and-users` | Scraper | REST API has no user/team DELETE |
| Email commands | Local / SMTP | Read CSV/templates locally; only `send-user-accounts` contacts SMTP |

`prefer_scraper=true` in `domserver.json` forces hybrid operations to
the scraper route. It does not move API-only reads such as scoreboard
or submission download off the API.

## Email Template Placeholders

`render-user-accounts` and `send-user-accounts` support exactly these
six placeholders in `subject.txt`, `body.txt`, and `body.html`:

| Placeholder | Source |
| ----------- | ------ |
| `$username` | CSV `username` column |
| `$name` | CSV `name` column |
| `$email` | CSV `email` column |
| `$affiliation` | CSV `affiliation` column |
| `$password` | CSV `password` column (or generated value) |
| `$server_host` | `domserver.json` `host` field |

Validate a template directory with:

```bash
domjudge-tool email-template-validate ./my-template
```
